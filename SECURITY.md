# Security

## Reporting a problem

Report a security problem privately, through GitHub's private vulnerability reporting: open the repository's **Security** tab and choose **Report a vulnerability**, or go to <https://github.com/birdtable/go-console/security/advisories/new>.

Never report one in a public issue, a pull request or a discussion.

Please say which version you use (the one your `go.mod` pins), which system, and the class of problem, for example "a cell can write a control sequence to the terminal". A short program that shows it helps. You will get an answer, and a fix goes out in a patch release before the problem is described in public.

## Supported versions

The latest minor version is supported. Fixes are made on it and released as a patch.
